# 🧪 ГАЙД ПО ТЕСТИРОВАНИЮ AI ИНТЕГРАЦИИ

## 🎯 **ЧТО ТЕСТИРУЕМ:**
Полный пайплайн AI рекомендаций на странице Preferences

## 📋 **ПОШАГОВОЕ ТЕСТИРОВАНИЕ:**

### **1. Подготовка:**
```bash
# Убедитесь, что сервер запущен
curl http://localhost:3001/api/benefits

# Убедитесь, что Claude API ключ установлен
echo $env:CLAUDE_API_KEY
```

### **2. Фронтенд тестирование:**

#### **🔸 Шаг 1: Открыть страницу**
- Перейти на http://localhost:3000/preferences  
- Должна показаться стартовая страница с "Smart Benefit Recommendations"

#### **🔸 Шаг 2: Заполнить свободные предпочтения (ОПЦИОНАЛЬНО)**
- Заполнить поле "Что вам важно?"
- Добавить теги в "Хочу" и "Не хочу"  
- Выбрать формат, бюджет, время
- Нажать "Сохранить предпочтения"

#### **🔸 Шаг 3: Начать тест**
- Нажать кнопку "Пройти тест"
- Пройти все 4 вопроса

#### **🔸 Шаг 4: Завершить тест - ключевой момент! 🔥**
- При ответе на последний (4-й) вопрос должно произойти:
  1. **Сразу появится модальное окно** "ИИ анализирует ваши предпочтения..."
  2. **Анимация:** Вращающийся мозг + загрузка
  3. **Через 3-5 секунд:** Галочка + "Анализ завершен!"
  4. **Можно закрыть** модалку кнопкой X

#### **🔸 Шаг 5: Проверить результаты**
- **Карточки рекомендаций:** Должны показаться с объяснениями от AI
- **AI отчет:** Под карточками должен появиться блок "AI Анализ ваших предпочтений"
- **Содержание отчета:** Персональные советы от Claude

### **3. Проверка API (для отладки):**

```javascript
// В консоли браузера проверить состояния:
// 1. Сохранение предпочтений
fetch('/api/ai-preferences', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    user_id: 1,
    free_text: 'тест',
    tags: ['спорт']
  })
}).then(r => r.json()).then(console.log)

// 2. Генерация AI рекомендаций  
fetch('/api/ai/recommendations/generate', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({user_id: 1})
}).then(r => r.json()).then(console.log)

// 3. Получение рекомендаций
fetch('/api/ai/recommendations?user_id=1')
.then(r => r.json()).then(console.log)
```

## 🚨 **ВОЗМОЖНЫЕ ПРОБЛЕМЫ:**

### **Модалка не появляется:**
- Проверить консоль браузера на ошибки
- Убедиться, что Claude API ключ установлен
- Проверить статус API: `curl http://localhost:3001/api/ai-preferences`

### **AI отчет не показывается:**
- Проверить, что `/api/ai/generate-personal-recommendations` работает
- Посмотреть Network tab в dev tools

### **Ошибки API:**
- Проверить логи Docker: `docker logs yoddle1-app-1 --tail 50`
- Убедиться, что база данных доступна
