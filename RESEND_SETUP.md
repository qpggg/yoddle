# 📧 Настройка Resend для отправки писем

## 🚀 Установка и настройка

### 1. Установка пакета
```bash
npm install resend
```

### 2. Получение API ключа
1. Зарегистрируйтесь на [resend.com](https://resend.com)
2. Создайте новый домен или используйте существующий
3. Получите API ключ в разделе API Keys

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
RESEND_API_KEY=re_your_actual_api_key_here
```

### 4. Настройка email адреса
В файле `api/clients.js` замените:
```javascript
to: ['your-email@gmail.com'], // Замените на ваш Gmail
```

## 🔧 Конфигурация

### Домен для отправки
- Используйте домен `yoddle.ru` или `noreply@yoddle.ru`
- Или создайте поддомен `mail.yoddle.ru`

### Проверка отправки
1. Запустите сервер: `npm run dev:server`
2. Отправьте тестовую заявку через форму на сайте
3. Проверьте логи сервера на наличие ошибок
4. Проверьте ваш Gmail на получение письма

## 📝 Формат письма

Письмо содержит:
- Красивый HTML шаблон в фирменных цветах Yoddle
- Информацию о клиенте (имя, email, компания, сообщение)
- Время отправки заявки
- Ссылку на сайт

## ⚠️ Важные моменты

1. **API ключ** - храните в секрете, не коммитьте в git
2. **Лимиты** - Resend имеет лимиты на количество писем
3. **Спам** - убедитесь, что форма защищена от спама
4. **Тестирование** - сначала протестируйте на тестовом домене

## 🐛 Возможные проблемы

### Ошибка "Invalid API key"
- Проверьте правильность API ключа
- Убедитесь, что файл `.env` загружается

### Ошибка "Domain not verified"
- Подтвердите домен в Resend
- Или используйте тестовый домен

### Письма не доходят
- Проверьте папку "Спам"
- Проверьте настройки домена в Resend
- Убедитесь, что домен правильно настроен в DNS
