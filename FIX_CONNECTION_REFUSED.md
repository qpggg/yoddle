# 🔴 РЕШЕНИЕ ОШИБКИ "Connection refused"

## ❌ Ошибка:

```
psql: error: connection to server at "localhost" (::1), port 5432 failed: Connection refused
Is the server running on that host and accepting TCP/IP connections?
```

## ✅ Что это означает:

**БД находится НЕ на этом сервере**, а на удаленном сервере вашего хостинг-провайдера.

PostgreSQL сервер не запущен на `localhost`, потому что БД создана через GUI провайдера и находится на отдельном сервере БД.

---

## 🔍 ШАГ 1: Найдите правильный хост в GUI провайдера

### Инструкция:

1. **Войдите в панель управления вашего хостинг-провайдера**
2. **Найдите раздел "Базы данных" / "Databases"**
3. **Откройте информацию о БД `f1111323_base`**
4. **Найдите параметр "Host" / "Server" / "Endpoint"**

### Где искать:

- **cPanel**: Базы данных → PostgreSQL → `f1111323_base` → "Детали подключения"
- **ISPmanager**: Базы данных → PostgreSQL → `f1111323_base` → "Параметры подключения"
- **Plesk**: Базы данных → `f1111323_base` → "Информация о подключении"
- **Другие панели**: Ищите раздел с информацией о БД

### Что скопировать:

- **Host** / **Server** / **Endpoint** - это может быть:
  - Доменное имя: `db.example.com`, `postgres.example.com`
  - IP адрес: `185.123.45.67`
  - Или другой адрес

- **Port** - обычно `5432`, но может отличаться

- **SSL** - требуется ли SSL подключение (обычно ДА для удаленных БД)

---

## 🔧 ШАГ 2: Подключитесь с правильным хостом

### Вариант 1: Без SSL (попробуйте сначала)

```bash
# Замените YOUR_DB_HOST на реальный хост из GUI провайдера
PGPASSWORD=lJS2b1O3 psql -h YOUR_DB_HOST -p 5432 -U f1111323_base -d f1111323_base -c "SELECT version();"
```

**Примеры:**
```bash
# Если хост = db.example.com
PGPASSWORD=lJS2b1O3 psql -h db.example.com -p 5432 -U f1111323_base -d f1111323_base -c "SELECT version();"

# Если хост = 185.123.45.67
PGPASSWORD=lJS2b1O3 psql -h 185.123.45.67 -p 5432 -U f1111323_base -d f1111323_base -c "SELECT version();"
```

### Вариант 2: С SSL (если без SSL не работает)

```bash
# Через строку подключения с SSL
PGPASSWORD=lJS2b1O3 psql "postgresql://f1111323_base:lJS2b1O3@YOUR_DB_HOST:5432/f1111323_base?sslmode=require" -c "SELECT version();"

# ИЛИ через параметры
PGPASSWORD=lJS2b1O3 psql "host=YOUR_DB_HOST port=5432 dbname=f1111323_base user=f1111323_base password=lJS2b1O3 sslmode=require" -c "SELECT version();"
```

## 🆘 Если все еще не работает:

### Проверьте:

1. **Правильность хоста** - скопировали точно из GUI?
2. **Правильность порта** - может быть не 5432?
3. **Требуется ли SSL** - попробуйте оба варианта
4. **Firewall** - может блокировать подключение?

### Альтернативные способы:

1. **Используйте готовую строку подключения** из GUI провайдера (если есть)
2. **Обратитесь в поддержку провайдера** - они дадут точные параметры
3. **Проверьте документацию провайдера** - там могут быть примеры подключения

---
