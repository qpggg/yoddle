# 🔄 Команды для перезапуска Telegram бота

## Быстрый перезапуск (если процесс существует)

```bash
# Проверьте статус
pm2 status

# Перезапустите бота
pm2 restart yoddle-tg

# Проверьте логи
pm2 logs yoddle-tg --lines 50
```

## Полный перезапуск (если процесс упал или не запускается)

```bash
# 1. Перейдите в директорию бота
cd /path/to/yoddle/telegram-bot

# 2. Остановите и удалите старый процесс (если есть)
pm2 stop yoddle-tg
pm2 delete yoddle-tg

# 3. Запустите бота заново
pm2 start ecosystem.config.js

# 4. Сохраните конфигурацию для автозапуска
pm2 save

# 5. Проверьте статус
pm2 status yoddle-tg

# 6. Посмотрите логи
pm2 logs yoddle-tg --lines 50
```

## Если бот не запускается

### Проверка .env файла

```bash
# Проверьте наличие BOT_TOKEN
cat ../.env | grep BOT_TOKEN

# Или если .env в директории бота
cat .env | grep BOT_TOKEN
```

### Проверка зависимостей

```bash
cd /path/to/yoddle/telegram-bot
npm install
```

### Проверка подключения к БД

```bash
# Проверьте PG_CONNECTION_STRING в .env
cat ../.env | grep PG_CONNECTION_STRING
```

### Просмотр ошибок

```bash
# Только ошибки
pm2 logs yoddle-tg --err --lines 100

# Все логи
pm2 logs yoddle-tg --lines 100
```

## Автоматический скрипт восстановления

Используйте готовый скрипт:

```bash
cd /path/to/yoddle
bash scripts/utils/restore_telegram_bot.sh
```

## Полезные команды PM2

```bash
# Статус всех процессов
pm2 status

# Логи в реальном времени
pm2 logs yoddle-tg

# Перезапуск
pm2 restart yoddle-tg

# Остановка
pm2 stop yoddle-tg

# Удаление из PM2
pm2 delete yoddle-tg

# Мониторинг
pm2 monit

# Сохранение конфигурации
pm2 save

# Настройка автозапуска при перезагрузке системы
pm2 startup
```
