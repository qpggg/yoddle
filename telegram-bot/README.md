# 🤖 Yoddle Telegram Bot

Telegram бот для лидогенерации HR-tech платформы Yoddle.

## 🎯 Назначение

Бот является ключевой точкой входа в воронку продаж Yoddle:
- Захват лидов из Telegram-сетки, форумов, мероприятий
- Онбординг и квалификация потенциальных клиентов
- Демонстрация возможностей платформы
- ИИ-взаимодействие для создания "вау-эффекта"
- Редирект на демо и коммерческие предложения

## 🚀 Функционал

### 1️⃣ Онбординг лида
- Определение роли (HR, C-Level, Собственник, Консультант)
- Сбор email для последующей коммуникации
- Выявление интересов (льготы, ИИ, геймификация, аналитика)

### 2️⃣ Мини-демо модулей
- **Льготы**: Каталог, активация 70-85%, экономия бюджета
- **ИИ-советник**: Персональные рекомендации, предсказание оттока
- **Геймификация**: XP, ранги, достижения, лидерборды
- **Аналитика**: Дашборд руководителя, ROI, отчеты

### 3️⃣ ИИ-советник (вау-эффект)
- Опрос настроения сотрудника
- Выявление задач и целей
- Генерация персонализированного фидбека через Claude API
- Создание эмоционального отклика

### 4️⃣ Редирект в оффер
- 📊 Получить презентацию
- 📞 Записаться на демо (Calendly)
- 🔔 Подписаться на обновления
- 🌐 Открыть сайт

## 📦 Установка

### 1. Установите зависимости
```bash
cd telegram-bot
npm install
```

### 2. Создайте бота у @BotFather
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям (название и username бота)
4. Скопируйте токен бота

### 3. Настройте переменные окружения
```bash
cp .env.example .env
```

Заполните `.env`:
```env
BOT_TOKEN=ваш_токен_от_botfather
DB_HOST=localhost
DB_PORT=5432
DB_NAME=yoddle_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
CLAUDE_API_KEY=ваш_ключ_claude_api
ADMIN_CHAT_ID=ваш_telegram_id
```

### 4. Инициализируйте базу данных
Бот автоматически создаст таблицу `telegram_leads` при первом запуске.

### 5. Запустите бота
```bash
# Development mode (с hot reload)
npm run dev

# Production mode
npm start
```

## 💾 База данных

### Таблица `telegram_leads`

| Поле | Тип | Описание |
|------|-----|----------|
| id | SERIAL | ID записи |
| telegram_id | BIGINT | Telegram ID пользователя |
| username | VARCHAR | Username в Telegram |
| first_name | VARCHAR | Имя |
| last_name | VARCHAR | Фамилия |
| role | VARCHAR | Роль (HR, C-Level, etc.) |
| email | VARCHAR | Email для связи |
| interests | TEXT[] | Массив интересов |
| source | VARCHAR | Источник (telegram_bot) |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата обновления |

## 🤖 ИИ-интеграция

Бот использует Claude API для генерации персонализированных советов:

1. **Основной**: Claude API (Anthropic)
2. **Резервный**: OpenRouter API
3. **Fallback**: Rule-based ответы

Если API недоступны, бот автоматически использует предзаготовленные шаблоны ответов.

- Отправляет лиды в CRM систему Yoddle

## 🐛 Troubleshooting

### Бот не отвечает
1. Проверьте токен в `.env`
2. Убедитесь, что бот запущен: `ps aux | grep node`
3. Проверьте логи: `pm2 logs yoddle-bot`

### Ошибки БД
1. Проверьте подключение к PostgreSQL
2. Убедитесь, что таблица создана: `\dt telegram_leads`

### ИИ не работает
1. Проверьте API ключи в `.env`
2. Бот автоматически переключится на fallback
