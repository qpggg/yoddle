# ⚙️ Настройка лимита AI-советника

## 📋 Конфигурация

**Максимальное количество запросов к AI-советнику: 3 в день**

Лимит строго ограничен и проверяется в двух местах:
1. **При входе в AI-советник** - проверка до начала заполнения формы
2. **Перед отправкой запроса к API** - дополнительная проверка перед анализом

## 🔍 Где настроено

### 1. Telegram Bot (`telegram-bot/src/services/leadService.js`)
```javascript
const MAX_REQUESTS_PER_DAY = 3;
```

### 2. API Server (`api/ai.js`)
```javascript
const limit = 3;
```

## ✅ Как работает

1. При нажатии кнопки "Попробовать ИИ-советника" проверяется количество использований за сегодня
2. Если лимит исчерпан (3/3), пользователю показывается сообщение:
   ```
   ⛔ Достигнут лимит использования ИИ-советника
   
   Вы использовали ИИ-советника 3/3 раз сегодня.
   
   Лимит обновится завтра. Вы сможете получить новые рекомендации с 00:00.
   ```

3. Если лимит не исчерпан, пользователь может пройти форму и получить рекомендацию

4. После получения рекомендации счетчик увеличивается

5. Перед отправкой запроса к API также выполняется проверка (на случай, если лимит исчерпался между входом и отправкой)

## 🔄 Сброс лимита

Лимит сбрасывается автоматически каждый день в 00:00 по серверному времени.

Проверка выполняется по полю `timestamp` в таблице `ai_signals`:
```sql
WHERE timestamp >= CURRENT_DATE
```

## 🛡️ Администраторы

Пользователи с `ADMIN_TELEGRAM_ID` из `.env` имеют неограниченный доступ к AI-советнику.

## 📊 Отслеживание в БД

Использования сохраняются в таблице `ai_signals`:
- `user_id` = 1 (для всех Telegram пользователей)
- `type` = 'mood'
- `data->>'telegram_id'` = telegram ID пользователя
- `timestamp` = время запроса

## 🔧 Изменение лимита

Чтобы изменить лимит, нужно обновить значение в двух местах:

1. **`telegram-bot/src/services/leadService.js`**:
   ```javascript
   const MAX_REQUESTS_PER_DAY = 5; // изменить на нужное значение
   ```

2. **`api/ai.js`**:
   ```javascript
   const limit = 5; // изменить на нужное значение
   ```

⚠️ **Важно**: Оба значения должны быть одинаковыми!
