# 🚀 Промпт для генерации вирусного поста про Telegram-бота Yoddle

## 📝 Промпт для GPT/Claude:

```
Создай вирусный пост-анонс для Telegram канала про HR-tech бота. 

КОНТЕКСТ:
Yoddle — первая в России HR-платформа с AI-советником и геймификацией. 
Запустили Telegram-бота @YoddleBot, который даёт персональные рекомендации HR-специалистам.

ОСОБЕННОСТИ БОТА:
- 🤖 AI-советник на базе Claude — анализирует настроение, энергию, стресс и даёт персональные рекомендации
- 💰 Управление корпоративными льготами — каталог с 100+ партнёрами
- 🎮 Геймификация — XP, ранги, достижения для сотрудников
- 📊 Аналитика в реальном времени

РЕЗУЛЬТАТЫ КЛИЕНТОВ:
- Текучесть снижается на 15-25%
- Удовлетворенность +30%
- Активация льгот: 70-85% (vs 20-30% обычно)
- Экономия HR-времени: 40-50 часов/месяц

ЦЕЛЕВАЯ АУДИТОРИЯ:
HR-директора, HR-менеджеры, C-Level, владельцы бизнеса 300-3000 сотрудников

ЗАДАЧА:
Создай вирусный пост для Telegram, который:
1. Вызовет любопытство и желание попробовать
2. Подчеркнёт уникальность (AI-советник, персональные рекомендации)
3. Покажет конкретные результаты (цифры, метрики)
4. Создаст срочность/желание "попробовать прямо сейчас"
5. Включает CTA (призыв к действию) — ссылку на бота @YoddleBot
6. Использует эмодзи, но не перегружает ими
7. Пишет на русском языке, живым языком
8. Длина: 300-500 символов (для Telegram оптимально)
9. Стиль: неформальный, но профессиональный, с элементами интриги

ФОРМАТ:
- Начни с хука (цепляющий первый абзац)
- Добавь конкретику (цифры, факты)
- Включи элемент интриги/эксклюзивности
- Закончи призывом попробовать

ПРИМЕРЫ ТОНАЛЬНОСТИ:
"🔥 Только что запустили..."
"💡 Представляете, если бы..."
"🎯 Вчера протестировали..."
"⚡ Это изменит подход к..."

СОЗДАЙ 3 ВАРИАНТА поста с разными подходами:
1. Вариант 1: Фокус на AI-советнике и персонализации
2. Вариант 2: Фокус на результатах и метриках клиентов
3. Вариант 3: Фокус на решении боли HR (выгорание, текучесть, рутина)

После каждого варианта добавь краткое объяснение: почему этот подход сработает для целевой аудитории.
```

## 🎯 Альтернативный упрощённый промпт:

```
Напиши вирусный пост в Telegram про HR-бота с AI-советником.

ФАКТЫ:
- Бот @YoddleBot
- Даёт персональные рекомендации HR через AI (Claude)
- Результаты: -15-25% текучесть, +30% удовлетворённость, 70-85% активация льгот
- Для компаний 300-3000 сотрудников

ТРЕБОВАНИЯ:
- 300-500 символов
- Цепляющий заголовок
- Конкретные цифры
- CTA с @YoddleBot
- Живой язык, эмодзи умеренно
- Интрига + срочность

Создай 3 варианта с разными углами: AI-магия / Результаты / Решение проблемы.
```

## 📱 Примеры возможных форматов поста:

### Формат 1: Интрига + Результат
```
🔥 Устали от рутины в HR? Запустили бота, который...

[Хук про проблему]
[Результат/Решение]
[CTA]
```

### Формат 2: Кейс + Тест
```
💡 Вчера протестировали AI-советника на реальной команде...

[Что сделали]
[Что получили]
[CTA]
```

### Формат 3: Вопрос + Решение
```
🤔 Что если ваш HR-специалист получал бы персональные рекомендации от AI?

[Проблема]
[Решение]
[Результаты]
[CTA]
```

## ✨ Дополнительные элементы для вирусности:

- **Эксклюзивность**: "Только что запустили", "Бета-версия", "Первые 100 пользователей"
- **Социальное доказательство**: "Уже протестировали 50+ HR", "Первая компания снизила текучесть на 22%"
- **Срочность**: "Попробуйте бесплатно до конца месяца", "Ограниченное количество"
- **Любопытство**: "Что будет, если...", "Представьте, что..."
- **Эмоции**: "Шокировало результаты", "Не ожидали такой отдачи"

---

## 🎨 Рекомендации по оформлению:

- Используй эмодзи для структурирования (🔥 для хука, ✅ для фактов, 🚀 для CTA)
- Разбей текст на короткие абзацы (2-3 строки)
- Выдели ключевые цифры **жирным** или заглавными
- Добавь разрыв строки перед CTA
- Ссылка на бота должна быть в конце
