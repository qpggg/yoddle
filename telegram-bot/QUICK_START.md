# 🚀 Быстрый запуск Telegram бота

## 📋 Шаги для запуска:

### 1️⃣ Создайте бота через @BotFather

1. Откройте Telegram → найдите `@BotFather`
2. Отправьте `/newbot`
3. Введите название: `Yoddle Assistant`
4. Введите username: `YoddleBot` (или другой доступный)
5. **Скопируйте токен** (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2️⃣ Настройте .env файл

Откройте файл `.env` и замените:
```env
BOT_TOKEN=ваш_токен_от_botfather
```

### 3️⃣ Запустите простую версию бота

```bash
npm run simple
```

### 4️⃣ Тестируйте бота

1. Найдите вашего бота в Telegram по username
2. Отправьте `/start`
3. Протестируйте все функции

## 🎯 Что умеет бот:

✅ **Онбординг лидов** - сбор роли, email, интересов  
✅ **Демо платформы** - показ модулей Yoddle  
✅ **ИИ-советник** - интерактивная демонстрация  
✅ **Запись на демо** - переход к календарю  
✅ **Презентация** - ссылка на PDF  

## 🔧 Команды:

- `/start` - начать знакомство
- `/demo` - посмотреть демо
- `/help` - список команд

## 📱 Тестирование:

1. Отправьте `/start`
2. Нажмите "🚀 Начать знакомство"
3. Выберите роль
4. Введите email
5. Выберите интересы
6. Протестируйте ИИ-советника

## ❌ Если что-то не работает:

1. Проверьте токен в .env файле
2. Убедитесь, что бот создан через @BotFather
3. Проверьте подключение к интернету
4. Перезапустите бота: `Ctrl+C` → `npm run simple`
