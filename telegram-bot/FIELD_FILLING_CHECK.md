**Проблема:** URL кнопки в Telegram не отправляют callback, поэтому клики по ссылке на сайт нельзя отследить напрямую через бота.

**Решение:** Использовать UTM параметры в URL и отслеживать на сайте через аналитику:
```javascript
Markup.button.url('🌐 Открыть сайт', 'https://yoddle.ru?utm_source=telegram_bot&telegram_id=' + ctx.from.id)
```

## 🔍 Проверка вызовов функций

### ✅ Вызываются правильно:

1. **`saveLead()`** - вызывается при завершении онбординга (строка 266)
2. **`incrementAIUsage()`** - вызывается после успешного использования ИИ (строка 881)
3. **`incrementDemoViews()`** - вызывается при просмотре каждого модуля:
   - `demo_benefits` → `incrementDemoViews(id, 'benefits')` (строка 356)
   - `demo_ai` → `incrementDemoViews(id, 'ai')` (строка 388)
   - `demo_gamification` → `incrementDemoViews(id, 'gamification')` (строка 421)
   - `demo_analytics` → `incrementDemoViews(id, 'analytics')` (строка 453)
4. **`updatePresentationRequested()`** - вызывается при запросе презентации (строка 1040)
5. **`updateDemoScheduled()`** - вызывается при записи на демо (строка 1112)
6. **`updateLastBotActivity()`** - вызывается через middleware при каждом действии (строка 55)

### ❌ НЕ вызывается:

1. **`updateWebsiteClick()`** - импортируется, но НИГДЕ не вызывается
   - **Причина:** URL кнопки в Telegram не отправляют callback
