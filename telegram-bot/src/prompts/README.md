# Промпты для генерации постов Yoddle

## Описание

Системный промпт для генерации вирусных постов для маркетинга Yoddle в Telegram, TenChat и Сетке (hh.ru).

## Файлы

- `post-generation-prompt.md` — основной системный промпт
- `post-generation-example.json` — пример JSON-формата вывода

## Использование

### Шаг 1: Подготовка контекста

Перед генерацией постов собери актуальный контекст:
- Статьи о HR-трендах 2025 (русские и зарубежные)
- Исследования рынка (McKinsey, Deloitte, SHRM и т.д.)
- Кейсы компаний (обезличенные или публичные)
- Статистика и данные (только проверенные!)

### Шаг 2: Запрос к AI

Передай промпт из `post-generation-prompt.md` в систему AI (Claude/OpenAI) вместе с контекстом:

```
[Вставить промпт из post-generation-prompt.md]

КОНТЕКСТ:
[Вставить собранные статьи, исследования, данные]
```

### Шаг 3: Проверка данных

**КРИТИЧЕСКИ ВАЖНО:** Все цифры, статистика, факты должны быть проверены через веб-поиск. Если AI не может проверить данные — используй обобщённые формулировки.

### Шаг 4: Получение результата

AI вернёт 4 поста в формате:
- Пост 1: Проблема рынка → Решение Yoddle + CTA
- Пост 2: Экспертный пост + CTA
- Пост 3: Интерактив (без CTA)
- Пост 4: Кейс + CTA

После каждого поста будет аналитика охватов.

### Шаг 5: Обработка

1. Замени `[ССЫЛКА_НА_БОТА]` на реальную ссылку
2. Проверь длину постов (600-900 знаков)
3. Проверь данные через веб-поиск
4. Адаптируй под конкретную площадку при необходимости

## Особенности каналов

### Telegram
- Первый экран критичен (первые 2 строки)
- Короткие абзацы, ритм
- Вопросы стимулируют комментарии

### TenChat
- Ограничение: 2 новых чата в день (бесплатно), 25 при подписке
- Посты самодостаточные (не требуют продолжения в чате)
- CTA ведёт на бота, не на чат

### Сетка (hh.ru)
- Профессиональный тон
- Конкретика и цифры ценятся
- Минимум внешних ссылок

## Важные правила

1. ✅ Все данные проверяются через веб-поиск
2. ✅ Тематика разнообразна (не только льготы/вовлечённость)
3. ✅ Посты уникальны каждый раз
4. ✅ Используется предоставленный контекст
5. ✅ После каждого поста есть аналитика

## JSON-формат

Для программной обработки можно запросить вывод в JSON-формате (см. `post-generation-example.json`).

## Интеграция с aiService.js

Промпт можно интегрировать в `telegram-bot/src/services/aiService.js` для автоматической генерации постов через Claude API.

Пример интеграции:
```javascript
const postPrompt = require('./prompts/post-generation-prompt.md');
const context = '...'; // собранный контекст

const response = await axios.post(
  'https://api.anthropic.com/v1/messages',
  {
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 4000,
    messages: [
      {
        role: 'user',
        content: `${postPrompt}\n\nКОНТЕКСТ:\n${context}`
      }
    ]
  }
);
```
