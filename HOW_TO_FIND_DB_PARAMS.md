# 🔍 КАК НАЙТИ ПАРАМЕТРЫ ПОДКЛЮЧЕНИЯ К БД В GUI ПРОВАЙДЕРА

## 📋 Где искать параметры подключения:

### 1. Войдите в панель управления хостинг-провайдера

Обычно это:
- **cPanel** (для shared hosting)
- **ISPmanager** (для VPS)
- **Plesk** (для VPS)
- **Веб-интерфейс провайдера** (у каждого свой)

### 2. Найдите раздел "Базы данных" или "Databases"

Обычно находится в меню:
- "Базы данных" / "Databases"
- "MySQL/PostgreSQL"
- "Управление БД" / "Database Management"

### 3. Откройте информацию о вашей БД `f1111323_base`

Нажмите на название БД или кнопку "Информация" / "Details" / "Connection Info"

### 4. Скопируйте следующие параметры:

#### Обязательные параметры:

- **Host / Server / Endpoint** 
  - Примеры: `localhost`, `127.0.0.1`, `db.example.com`, `185.123.45.67`
  - ⚠️ Это самый важный параметр!

- **Port**
  - Обычно: `5432` (стандартный PostgreSQL)
  - Может быть: `5433`, `6543` или другой

- **Database Name**
  - У вас: `f1111323_base`

- **Username**
  - У вас: `f1111323_base`

- **Password**
  - У вас: `lJS2b1O3`

#### Дополнительные параметры:

- **SSL Mode** / **SSL Required**
  - `require` - требуется SSL (обычно для удаленных БД)
  - `disable` - SSL не требуется (обычно для localhost)
  - `prefer` - предпочтительно, но не обязательно

- **Connection String** (если есть)
  - Готовая строка подключения типа:
  - `postgresql://user:password@host:port/database`

## ✅ Как проверить правильность параметров:

### Если хост = `localhost` или `127.0.0.1`:

БД находится на том же сервере, используйте команды с `localhost`:

```bash
PGPASSWORD=lJS2b1O3 psql -h localhost -U f1111323_base -d f1111323_base -c "SELECT version();"
```

### Если хост = внешний IP или доменное имя:

БД находится на удаленном сервере, используйте команды с указанием хоста:

```bash
# Замените YOUR_DB_HOST на реальный хост из GUI
PGPASSWORD=lJS2b1O3 psql -h YOUR_DB_HOST -p 5432 -U f1111323_base -d f1111323_base -c "SELECT version();"
```

## 🆘 Если не можете найти параметры:

1. **Обратитесь в поддержку провайдера** - они должны предоставить параметры подключения
2. **Проверьте документацию провайдера** - обычно есть инструкции по подключению к БД
3. **Проверьте email** - некоторые провайдеры отправляют параметры подключения на email при создании БД
