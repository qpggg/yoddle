Yoddle - HR-Tech Платформа для управления корпоративными льготами

Современная платформа управления корпоративными льготами с элементами геймификации и искусственного интеллекта для малого, среднего и крупного бизнеса.

О ПРОЕКТЕ

Yoddle - платформа "кафетерий льгот" для компаний: единый магазин льгот с балансом в Yoddle-coins, персональные рекомендации и механики вовлечения.

Сотрудник заходит в приложение, видит понятный каталог (здоровье/спорт/обучение), выбирает льготы на свой баланс, получает рекомендации от ИИ на основе короткого теста, предпочтений и поведения. Встроены отчёты самочувствия/успехов и анализ активности - ИИ даёт поддержку и следующие шаги. Есть геймификация: достижения и прогресс за полезные действия.

Для компании это превращает льготы и инициативы в управляемую систему с понятной активностью и аналитикой, а не "разрозненные штуки".

Ключевые особенности

Геймификация - XP, ранги, достижения, лидерборды
AI-рекомендации - персонализированные предложения льгот на основе теста, предпочтений и поведения
Система Yoddle-coins - баланс для выбора льгот
Отчёты самочувствия и активности - анализ состояния сотрудников
Админ-панель для HR - управление сотрудниками, аналитика, отчёты

УСТАНОВКА И ЗАПУСК

1. Клонирование репозитория
git clone [repository-url]
cd yoddle

2. Установка зависимостей
npm install

3. Настройка переменных окружения
cp .env.example .env
Заполните необходимые переменные (подключение к БД, API ключи)

4. Запуск через Docker
docker compose up

Или локально без Docker:
npm run dev

5. Сборка для продакшена
npm run build

БАЗА ДАННЫХ

Проект использует PostgreSQL. SQL скрипты для настройки БД находятся в scripts/sql/:
database_setup.sql - базовая структура БД
ai_database_setup.sql - структура AI таблиц
gamification_setup.sql - настройка геймификации
performance_optimization.sql - оптимизация БД
