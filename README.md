# 🚀 Yoddle - HR-Tech Платформа для SMB и Enterprise

Современная платформа управления корпоративными льготами с элементами геймификации и искусственного интеллекта для малого, среднего и крупного бизнеса.

## 🎯 О ПРОЕКТЕ

**Yoddle** - это инновационная HR-tech платформа, которая автоматизирует управление корпоративными льготами, повышает вовлеченность сотрудников через геймификацию и предоставляет персонализированные рекомендации с помощью AI.

### 🌟 Ключевые особенности
- **Геймификация** - XP, ранги, достижения, лидерборды
- **AI-рекомендации** - персонализированные предложения льгот
- **Гибкие тарифы** - от 200₽ до 1,200₽/сотрудник/месяц
- **Enterprise решения** - API интеграции, white-label, SLA
- **Масштабируемость** - готов к 20,000+ пользователям

## 💰 НОВАЯ БИЗНЕС-МОДЕЛЬ

- **🥉 Базовый:** 200₽/сотрудник/месяц

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [repository-url]
cd yoddle1
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
```bash
cp .env.example .env
# Заполните необходимые переменные
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```

### 5. Сборка для продакшена
```bash
npm run build
```
