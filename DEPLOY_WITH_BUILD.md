# 🔧 ПОЛНАЯ ИНСТРУКЦИЯ: Обновление кода, сборка и запуск

## ✅ ПОРЯДОК ДЕЙСТВИЙ НА СЕРВЕРЕ:

### ШАГ 1: Обновите код

```bash
cd /root/yoddle
git pull origin stable
```

### ШАГ 2: Установите зависимости (если нужно)

```bash
# Проверьте, установлены ли зависимости
npm list --depth=0

# Если нужно установить/обновить:
npm install
```

### ШАГ 3: Соберите проект

```bash
# Соберите фронтенд (TypeScript + Vite)
npm run build
```

Это создаст папку `dist/` с собранным фронтендом.

### ШАГ 4: Остановите старые процессы

```bash
pm2 stop all
pm2 delete all
```

### ШАГ 5: Запустите приложение

```bash
pm2 start ecosystem.config.js

# Проверьте статус
pm2 status

# Проверьте логи
pm2 logs yoddle-api --lines 50
```

## ⚠️ ВАЖНО:

- **Сборка обязательна** - без `npm run build` фронтенд не будет работать
- **После каждого `git pull`** нужно пересобрать проект

Выполните команды на сервере!
