### 4.4. Система сбора данных для валидации пилота (1 день)

**Цель:** Собрать данные для оценки успешности пилота по метрикам

**График сбора:** Собираем еженедельно, подводим итоги в конце пилота. По необходимости — eNPS и пульс-опросы.

**Два типа сбора данных:**

#### 1. Автоматические метрики (из системы)

**Собираются автоматически из БД:**

**Вовлечённость:**
- Доля начавших пользоваться (≥70%)
  - SQL: `SELECT COUNT(DISTINCT user_id) FROM activity_log / total_users`
- Участие в активностях (≥50%)
  - SQL: `SELECT COUNT(DISTINCT user_id) FROM activity_log WHERE action = 'mood_entry' / total_users`
- Соотношение еженедельной/ежемесячной активности (≥0.5)
  - SQL: `SELECT weekly_active / monthly_active FROM activity_stats`
