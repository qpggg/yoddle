## 🎯 ОБЩАЯ СТРАТЕГИЯ

**Принцип:** Делаем по одному маленькому шагу за раз. Каждый шаг должен быть выполним за 1-4 часа.

**Порядок работы:**
1. Сначала улучшаем UX для сотрудников (чтобы они поняли как пользоваться)
2. Потом исправляем баги (чтобы всё работало стабильно)
3. Затем делаем админ-панель для HR (чтобы можно было управлять)
4. В конце настраиваем метрики и тестируем
