# ОБЪЯСНЕНИЕ: Почему средняя энергия NULL и настроение большое

## 📊 АНАЛИЗ ДАННЫХ ПОЛЬЗОВАТЕЛЯ 3

### 1. Почему средняя энергия NULL?

**Причина:** Поле `energy_rating` **НЕ ЗАПОЛНЕНО** в последних записях настроения.

**Доказательства:**

#### За последние 7 дней (только 2 записи от 28 января):
| Дата | Время | Настроение | Энергия | Стресс | Заметка |
|------|-------|------------|---------|--------|---------|
| 28.01 | 20:28 | **10** | **NULL** ❌ | 3 | "сделал фичу и сайт работает" |
| 28.01 | 19:54 | **9** | **NULL** ❌ | 5 | "Ответил презентацию перед коллективом" |

**Результат:** 
- Из 2 записей за неделю: **0 записей с заполненной энергией** (0%)
- Средняя энергия: **NULL** (нельзя посчитать среднее от NULL значений)

#### За всю историю пользователя 3:
- Всего записей настроения: **16**
- Записей с заполненной энергией: **14** (87.5%)
- Записей БЕЗ энергии: **2** (12.5%) ← **это последние 2 записи от 28 января!**

**Вывод:** Пользователь **не заполнял поле "энергия"** при последних двух записях настроения, поэтому средняя энергия за последние 7 дней = NULL.

---

### 2. Почему настроение такое большое (95%)?

**Причина:** Обе записи за последние 7 дней имеют **очень высокие значения настроения**.

**Расчет:**
- Запись 1: настроение = **10** (максимум!)
- Запись 2: настроение = **9** (почти максимум!)
- Среднее: (10 + 9) / 2 = **9.5**
- В процентах: 9.5 × 10 = **95%**

**Контекст записей:**
1. "сделал фичу и сайт работает" → настроение **10** (отличное!)
2. "Ответил презентацию перед коллективом и защитил проект" → настроение **9** (очень хорошее!)

**Вывод:** Пользователь был в **отличном настроении** в эти дни (успешные проекты, защита презентации), поэтому среднее настроение получилось очень высоким.

## 💡 ВОЗМОЖНЫЕ ПРИЧИНЫ

### Почему пользователь не заполнил энергию?

1. **Упрощенная форма ввода** - возможно, форма настроения была изменена и поле энергии стало опциональным
2. **Забыл заполнить** - пользователь просто пропустил это поле
3. **Быстрый ввод** - пользователь хотел быстро записать настроение и пропустил энергию
4. **Изменение интерфейса** - возможно, поле энергии было скрыто или сделано необязательным

---

## 🔧 РЕКОМЕНДАЦИИ

### Для исправления проблемы:

1. **Сделать поле энергии обязательным** в форме ввода настроения
2. **Показывать предупреждение**, если пользователь не заполнил энергию
3. **Использовать значение по умолчанию** (например, среднее из предыдущих записей) если поле не заполнено
4. **Фильтровать NULL значения** при расчете средних (использовать только заполненные записи)

### Для расчета средних значений:

**Текущая логика (проблемная):**
```sql
AVG(energy_rating) -- возвращает NULL если все значения NULL
```

**Рекомендуемая логика:**
```sql
AVG(energy_rating) FILTER (WHERE energy_rating IS NOT NULL) 
-- или
COALESCE(AVG(energy_rating), 0) -- вернет 0 вместо NULL
```
