# Как правильно начислять баланс пользователю

## Важно! 
**Начисление баланса должно быть доступно ТОЛЬКО администраторам, а не обычным сотрудникам в их кабинете.**

## Правильный способ начисления баланса

### 1. Использование API endpoint (рекомендуется)

Используйте endpoint `/api/wallet/credit` для начисления баланса:

```javascript
// Пример запроса
const response = await fetch('/api/wallet/credit', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    user_id: 4,                    // ID пользователя
    amount: 10000,                 // Сумма для начисления
    description: 'Тестовый баланс', // Описание (опционально)
    transaction_type: 'admin_add'  // Тип: 'admin_add', 'credit', или 'monthly_allowance'
  })
});

const data = await response.json();
// { success: true, balance: 10000, amount: 10000, balance_before: 0, balance_after: 10000 }
```

### 2. Что происходит внутри функции `creditHandler`:

1. **Валидация данных** - проверка user_id и amount
2. **Транзакция БД** - BEGIN для атомарности
3. **Блокировка баланса** - SELECT ... FOR UPDATE для предотвращения гонок
4. **Создание транзакции** - INSERT в `coin_transactions` с типом 'admin_add', 'credit' или 'monthly_allowance'
5. **Обновление баланса** - UPDATE `user_balance`, увеличивая `balance` и `total_earned`
6. **Коммит** - COMMIT транзакции

### 3. Типы транзакций для начисления:

- `admin_add` - начисление администратором (по умолчанию)
- `credit` - кредит/пополнение
- `monthly_allowance` - месячное начисление

### 4. Пример SQL для прямого начисления (если нужно):

```sql
-- 1. Создать транзакцию
INSERT INTO coin_transactions (
  user_id, 
  transaction_type, 
  amount, 
  balance_before, 
  balance_after, 
  description, 
  created_at
)
VALUES (
  4,                          -- user_id
  'admin_add',               -- тип транзакции
  10000,                     -- сумма
  0,                         -- баланс до
  10000,                     -- баланс после
  'Тестовый баланс',         -- описание
  NOW()
);

-- 2. Обновить баланс пользователя
INSERT INTO user_balance (user_id, balance, total_earned, total_spent, updated_at)
VALUES (4, 10000, 10000, 0, NOW())
ON CONFLICT (user_id) DO UPDATE 
SET 
  balance = user_balance.balance + 10000,
  total_earned = user_balance.total_earned + 10000,
  updated_at = NOW();
```

### 5. Важные моменты:

- ✅ **Всегда используйте транзакции БД** для атомарности операций
- ✅ **Блокируйте строку баланса** (SELECT ... FOR UPDATE) перед обновлением
- ✅ **Создавайте запись в coin_transactions** для истории операций
- ✅ **Обновляйте user_balance** синхронно с транзакцией
- ❌ **НЕ обновляйте баланс напрямую** без создания транзакции
- ❌ **НЕ давайте доступ к начислению** обычным пользователям
