### 1. DBeaver (Рекомендуется) ⭐

**Бесплатный, открытый, универсальный инструмент**

#### Установка через Snap:
```bash
sudo snap install dbeaver-ce
```

#### Установка через AppImage:
1. Скачайте с https://dbeaver.io/download/
2. Сделайте исполняемым: `chmod +x dbeaver-ce-*.AppImage`
3. Запустите: `./dbeaver-ce-*.AppImage`

### 2. pgAdmin (Официальный инструмент PostgreSQL)

#### Установка:
```bash
sudo apt-get update
sudo apt-get install pgadmin4
```

Или через веб-версию:
```bash
docker run -p 5050:80 \
  -e PGADMIN_DEFAULT_EMAIL=admin@admin.com \
  -e PGADMIN_DEFAULT_PASSWORD=admin \
  dpage/pgadmin4
```

Затем откройте http://localhost:5050

## Быстрый старт

### Применить миграцию онбординга:

**Вариант А: Через скрипт (если установлен psql)**
```bash
cd /home/bachira/Документы/yoddle
./scripts/apply_migration.sh
```

**Вариант Б: Через Docker (если БД в контейнере)**
```bash
docker exec -i your_postgres_container psql -U yoddle_user -d yoddle_db < scripts/sql/add_onboarding_fields.sql
```

**Вариант В: Через любой GUI инструмент**
1. Откройте SQL файл: `scripts/sql/add_onboarding_fields.sql`
2. Скопируйте содержимое
3. Выполните в вашем инструменте (DBeaver, pgAdmin и т.д.)

## Проверка миграции

После применения миграции проверьте, что поля добавлены:

```sql
\d user_progress
```

Должны появиться поля:
- `onboarding_completed` (BOOLEAN)
- `tour_completed` (BOOLEAN)
- `onboarding_completed_at` (TIMESTAMP)
- `tour_completed_at` (TIMESTAMP)
