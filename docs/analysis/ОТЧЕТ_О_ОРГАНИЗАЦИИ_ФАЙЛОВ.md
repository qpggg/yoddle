## 📝 Правила размещения новых файлов

### Документация (`docs/`):

1. **Описания платформы** → `docs/descriptions/`
   - Описания для разных аудиторий
   - Маркетинговые материалы

2. **Планы работы** → `docs/plans/`
   - Планы разработки
   - Планы подготовки к пилотам
   - Описания для клиентов

3. **Руководства** → `docs/guides/`
   - Инструкции по настройке
   - Руководства для разработчиков
   - Quick start гайды

4. **Анализы и отчеты** → `docs/analysis/`
   - Анализы платформы
   - Отчеты о работе
   - Технические анализы

5. **AI документация** → `docs/ai/`
   - Описание AI систем
   - Документация AI модулей

6. **Промпты** → `docs/prompts/`
   - Промпты для AI систем
   - Шаблоны промптов

7. **Бизнес документы** → `docs/business/`
   - PDF документы
   - Контакты
   - Бизнес-модели

8. **Логи работы** → `docs/work-log/`
   - Дневники работы
   - Ежедневные отчеты

### Файлы в корне проекта:

**Разрешены только:**
- `README.md` - основное описание проекта
- Конфигурационные файлы (`.env.example`, `package.json`, `docker-compose.yml`, и т.д.)
- `СТРУКТУРА_ПРОЕКТА.md` - структура проекта (в `docs/`)

**Запрещены:**
- Планы работы (→ `docs/plans/`)
- Руководства (→ `docs/guides/`)
- Описания (→ `docs/descriptions/`)
- Любые другие MD файлы документации
