## 🎯 ОБЩЕЕ ОПИСАНИЕ

**Yoddle** — это B2B SaaS платформа для управления корпоративными льготами с элементами геймификации и персонализации. Платформа предназначена для малого и среднего бизнеса (SMB) в России и помогает компаниям автоматизировать процесс предоставления льгот сотрудникам.

### Ключевая ценность:
- **Для компаний:** Снижение текучести кадров на 30-50%, автоматизация HR-процессов, повышение вовлеченности сотрудников
- **Для сотрудников:** Персонализированные льготы, геймификация, система мотивации через Yoddle-коины

## 💼 БИЗНЕС-МОДЕЛЬ

### Целевой рынок:
- **Сегмент:** Малый и средний бизнес (SMB) в России
- **Размер компаний:** 10-200 сотрудников
- **Адресный рынок:** ~6 млн SMB компаний в России
- **География:** Начало с Москвы и Санкт-Петербурга, затем регионы

### Тарифные планы:

| План | Цена/сотрудник/мес | Льготы | Целевая аудитория |
|------|-------------------|--------|-------------------|
| **Freemium** | 0₽ | Базовая платформа + 1 льгота/мес | До 10 сотрудников |

| **Стандарт** | 1,999₽ | Платформа + 2 льготы на выбор | 50-150 сотрудников |

### Монетизация:
1. **Подписочная модель (SaaS):** Ежемесячная плата за платформу
2. **Yoddle-коины:** Дополнительная валюта для покупки льгот (150-450₽/сотрудник/мес)
3. **Transaction fees:** Комиссия с поставщиков льгот (20-30%)
4. **Маржа:** 40-60% при правильных закупках

## 🏗️ ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### Frontend:
- **Фреймворк:** React 18.2.0 + TypeScript 5.3.3
- **UI библиотека:** Material-UI 5.17.1
- **Анимации:** Framer Motion 11.18.2
- **Роутинг:** React Router DOM 6.22.1
- **Сборщик:** Vite 5.1.4
- **Иконки:** Lucide React, React Icons

### Backend:
- **Сервер:** Express.js 5.1.0 (Node.js >=20.0.0)
- **База данных:** PostgreSQL (Supabase)
- **Аутентификация:** bcryptjs для хеширования паролей
- **API:** RESTful архитектура
- **AI:** Claude API (Anthropic) - @anthropic-ai/sdk ^0.18.0

### Инфраструктура:
- **Хостинг БД:** Supabase (AWS EU North-1)
- **Деплой:** Vercel (настроен)
- **CDN:** Cloudflare (планируется)
- **Мониторинг:** В разработке

## 📈 API ENDPOINTS

### Аутентификация:
- `POST /api/login` — Вход пользователя
- `GET /api/profile` — Получение профиля

### Льготы:
- `GET /api/benefits` — Список льгот
- `GET /api/user-benefits` — Льготы пользователя
- `POST /api/user-benefits` — Добавление льготы

### Геймификация:
- `GET /api/progress` — Прогресс пользователя
- `GET /api/activity` — Активность пользователя
- `POST /api/activity` — Логирование активности

### Yoddle-коины:
- `GET /api/balance?action=balance` — Получение баланса
- `GET /api/balance?action=transactions` — История транзакций (с фильтрацией по периодам)
- `POST /api/balance` — Операции с коинами:
  - `action=add_coins` — Добавление коинов (админ)
  - `action=spend_coins` — Списание коинов (покупка льгот)
  - `action=monthly_allocation` — Ежемесячное начисление

### Рекомендации:
- `GET /api/user-recommendations?user_id=X` — Получение рекомендаций пользователя
- `POST /api/user-recommendations` — Сохранение новых рекомендаций (после теста)
- `DELETE /api/user-recommendations` — Удаление рекомендаций

### AI Endpoints (Claude API):
- `POST /api/ai/analyze-mood` — Анализ настроения пользователя
- `POST /api/ai/log-activity` — Логирование активности с AI обратной связью
- `GET /api/ai/insights/:userId` — Получение всех AI инсайтов
- `GET /api/ai/recommendations?userId=:userId` — Получение AI рекомендаций
- `POST /api/ai/generate-daily-insight` — Генерация дневного инсайта
- `POST /api/ai/weekly-analysis` — Недельный анализ данных
- `POST /api/ai/preferences` — AI рекомендации льгот
- `POST /api/ai/analyze-trends` — Анализ трендов
- `POST /api/ai/force-weekly-insight` — Принудительная генерация недельного инсайта

### Уведомления:
- `GET /api/notifications` — Список уведомлений
- `POST /api/notifications/read` — Отметить прочитанным

### Новости:
- `GET /api/news` — Список новостей

### Контакты:
- `POST /api/clients` — Отправка заявки с лендинга
