### 3. Исправление еженедельных отчетов

- **Проблемы, которые были исправлены:**
  - Недельный отчет не генерировался из-за неправильного SQL запроса
  - Использовался `NOW() - INTERVAL '7 days'`, что не учитывало сегодняшний день
  - Неправильная обработка `userId` (fallback на userId=1)
  - Неправильное использование состояния на фронтенде (`dailyInsight` вместо `weeklyInsight`)

- **Выполненные исправления:**
  - Исправлен SQL запрос: `DATE(timestamp) >= (CURRENT_DATE - INTERVAL '6 days')` для корректного получения 7 полных дней
  - Добавлена валидация `userId` в API (возвращает 400 ошибку если отсутствует)
  - Исправлено использование состояния на фронтенде (используется `weeklyInsight` вместо `dailyInsight`)
  - Улучшена обработка данных настроения и активностей из БД
  - Добавлена проверка минимального количества записей (минимум 3 для генерации отчета)

  - ✅ Недельный отчет корректно генерируется для всех пользователей
