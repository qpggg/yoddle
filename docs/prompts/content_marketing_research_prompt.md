# 🔬 ПРОМПТ ДЛЯ ГЛУБОКОГО ИССЛЕДОВАНИЯ: Контент-маркетинг и продажи в TenChat, Сетка (hh.ru) и Telegram

## 🎯 КОНТЕКСТ ПРОЕКТА

**Проект:** Yoddle - HR-tech платформа для управления корпоративными льготами с AI и геймификацией

**Продукт:**
- SaaS-платформа для автоматизации управления корпоративными льготами
- AI-рекомендации персонализированных льгот для сотрудников
- Система геймификации (XP, ранги, достижения, лидерборды)
- Аналитика вовлеченности и продуктивности сотрудников
- Кабинет руководителя с дашбордами и отчетами


**Бизнес-модель:**
- Тарифы: 400 руб в месяц на сотрудника в месяц saas + стоимость льгот фикс на сотрудника в зависимости от грейда 
- Sales cycle: 1-4 недели (SMB), 1-2 месяца (Mid-size), 3-6 месяцев (Enterprise)
- Ценностное предложение: повышение вовлеченности сотрудников на 30%+, снижение текучести кадров, автоматизация HR-процессов

**Текущие задачи:**
1. Контент-маркетинг для привлечения целевой аудитории
2. Поиск клиентов для пилотов (3-5 первых клиентов для валидации)
3. Поиск респондентов для UX-исследовательских интервью (HR-специалисты, руководители)
