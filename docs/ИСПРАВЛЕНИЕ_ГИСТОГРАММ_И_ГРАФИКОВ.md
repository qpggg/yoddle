## 📊 УСЛОВИЯ ФОРМИРОВАНИЯ НЕДЕЛЬНОГО ОТЧЕТА

### Минимальные требования:
1. **Минимум 3 записи** за последние 7 дней
2. Записи должны быть типа `'mood'`, `'daily_mood_check'`, `'activity'` или `'activity_analysis'`
3. Данные должны быть в таблице `ai_signals`

### Логика формирования:
- Проверяется наличие записей за последние 7 дней
- Если записей меньше 3 → возвращается сообщение "Недостаточно данных"
- Если записей достаточно → генерируется AI анализ через Claude API
- Результат сохраняется в таблицу `ai_insights` с типом `'weekly_insight'`

### Автоматическое формирование:
- Недельный отчет формируется автоматически при вызове `/api/ai/generate-daily-insight` с параметром `forceRegenerate: false`
- Если отчет уже существует за текущую неделю → возвращается существующий
- Если `forceRegenerate: true` → генерируется новый отчет
