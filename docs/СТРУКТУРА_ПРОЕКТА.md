## 🗄️ База данных

### SQL Setup файлы (`scripts/sql/`):
Эти файлы используются для создания новой БД с нуля:

- `database_setup.sql` - базовая структура БД
- `ai_database_setup.sql` - структура AI таблиц
- `gamification_setup.sql` - настройка геймификации
- `notifications_system_setup.sql` - настройка уведомлений
- `news_system_setup.sql` - настройка новостей
- `feedback_system_setup.sql` - настройка обратной связи
- `create_activity_table.sql` - создание таблицы активности
- `create_benefit_recommendations.sql` - создание рекомендаций
- `create_user_recommendations.sql` - создание пользовательских рекомендаций
- `create_clients_table.sql` - создание таблицы клиентов
- `database_leads_simple.sql` - таблица для Telegram бота
- `performance_optimization.sql` - оптимизация БД
- `init.sql` - инициализация БД

**Примечание:** SQL файлы миграций удалены, так как БД уже развернута на сервере.
