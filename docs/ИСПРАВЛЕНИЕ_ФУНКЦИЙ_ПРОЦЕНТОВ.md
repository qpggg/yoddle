## ✅ ИСПРАВЛЕНО

### Проблема:
Функция `get_weekly_average_percentages` возвращала неправильные данные:
- Показывала **49%, 48%, 42%** вместо реальных **74%, 72%, 67%** для пользователя 4
- Возвращала средние значения (1-10) вместо процентов (0-100)

### Решение:
Создана новая правильная версия функции, которая:
1. **Умножает средние значения на 10** для получения процентов (0-100)
2. **Использует правильный период** - последние 7 дней до текущего дня
3. **Обрабатывает NULL значения** - возвращает 0 если данных нет

## 🔧 ИЗМЕНЕНИЯ

### 1. Функция `get_weekly_average_percentages`:
```sql
-- БЫЛО (неправильно):
AVG(mood_rating) -- возвращало значения 1-10

-- СТАЛО (правильно):
COALESCE(ROUND(AVG(mood_rating) * 10, 1), 0) -- возвращает проценты 0-100
```

### 2. Функция `get_weekly_mood_percentages`:
- Теперь возвращает проценты (0-100) для каждого дня
- Правильно обрабатывает дни без данных (возвращает 0)
