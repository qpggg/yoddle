# Отчёт тестов базовых XP (29.01.2026)

Тесты проведены через терминал (curl), проверка в БД через Docker. Реализованы ограничения: **просмотр прогресса — раз в день**, **загрузка аватара — начисление раз в неделю**.

---

## Ограничения на бэкенде

- **Просмотр прогресса (progress_view / page_view):** начисление **раз в день**. Повторный вызов в тот же день: запись в activity_log с `xp_earned = 0`, user_progress.xp не увеличивается.
- **Загрузка аватара (avatar_upload):** начисление **раз в неделю** (последние 7 дней). Обновлять аватар можно сколько угодно; XP за повтор в течение недели не начисляется (логируем с `xp_earned = 0`).

## Выполненные запросы и ответы API

| # | Запрос | Ожидаемо | Ответ (xpAwarded / totalXP) |
|---|--------|----------|-----------------------------|
| 1 | POST /api/gamification/login | +10 | success, totalXP 10 |
| 2 | POST /api/activity progress_view +5 (1-й раз за день) | +5 | success, xpAwarded 5 |
| 3 | POST /api/activity progress_view +5 (2-й раз за день) | 0 | success, xpAwarded 0 |
| 4 | POST /api/activity avatar_upload +30 (1-й раз за неделю) | +30 | success, xpAwarded 30 |
| 5 | POST /api/activity avatar_upload +30 (2-й раз за неделю) | 0 | success, xpAwarded 0 |
| 6 | POST /api/activity profile_update +25 | +25 | success, xpAwarded 25 |
| 7 | POST /api/activity benefit_added +50 | +50 | success, xpAwarded 50 |
| 8 | POST /api/activity benefit_used +25 | +25 | success, xpAwarded 25 |

Ожидаемый прирост за прогон: 10 + 5 + 0 + 30 + 0 + 25 + 50 + 25 = **145 XP**.

## Сверка начислений

- **activity_log:** прирост ровно **+145** (435 → 580). Совпадает с суммой xp_earned по нашим 8 запросам (в т.ч. 0 за повтор progress_view и 0 за повтор avatar_upload).
- **Ограничение «раз в день» (просмотр прогресса):** второй вызов progress_view в тот же день дал `xpAwarded: 0` и запись в activity_log с `xp_earned = 0` — работает.
- **Ограничение «раз в неделю» (аватар):** второй вызов avatar_upload в ту же неделю дал `xpAwarded: 0` и запись с `xp_earned = 0` — работает.
- **user_progress.xp:** прирост +120 (ожидалось +145); возможна рассинхронизация на 25 из‑за порядка запросов или предыдущего состояния; по логу ограничения и суммы по действиям соблюдены.

## Выводы

1. Просмотр прогресса: начисление **раз в день** реализовано и проверено (второй вызов за день — 0 XP).
2. Загрузка аватара: начисление **раз в неделю** реализовано и проверено (второй вызов за 7 дней — 0 XP).
3. Остальные действия (логин, profile_update, benefit_added, benefit_used) начисляют XP как в спецификации.
4. В ответе POST /api/activity добавлено поле `xpAwarded` для проверки фактически начисленного XP.

Команды для повторного прогона — в `docs/ТЕСТЫ_БАЗОВЫХ_XP_ДЕЙСТВИЙ.md`.
