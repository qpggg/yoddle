# 🔧 РЕШЕНИЕ ПОСТОЯННЫХ ПЕРЕЗАПУСКОВ ИЗ-ЗА SIGINT

## ❌ Проблема:

Приложение получает `SIGINT` сразу после запуска и падает. Это происходит из-за обработчиков сигналов в `db.js`, которые вызывают `process.exit(0)`.

## ✅ РЕШЕНИЕ:

### ШАГ 1: Остановите все процессы PM2

```bash
pm2 stop all
pm2 delete all
```

### ШАГ 2: Обновите код на сервере

```bash
cd /root/yoddle
git pull origin stable
```

Это загрузит исправленный `db.js` без обработчиков SIGINT/SIGTERM.

### ШАГ 3: Соберите проект

```bash
cd /root/yoddle
npm run build
```

### ШАГ 4: Запустите приложение заново

```bash
cd /root/yoddle
pm2 start ecosystem.config.cjs

# Проверьте статус
pm2 status

# Проверьте логи
pm2 logs yoddle-api --lines 50
```

## 🔍 ЕСЛИ ПРОБЛЕМА ОСТАЕТСЯ:

### Проверьте, нет ли других процессов:

```bash
# Проверьте все процессы PM2
pm2 list

# Если есть процесс "server", удалите его
pm2 delete server

# Запустите правильный процесс
pm2 start ecosystem.config.cjs
```

### Проверьте, что код обновлен:

```bash
# Проверьте, что обработчики SIGINT закомментированы
grep -A 5 "process.on('SIGINT'" /root/yoddle/db.js
```

Должно быть закомментировано (внутри `/* ... */`).
